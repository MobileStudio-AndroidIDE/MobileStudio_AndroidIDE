### ✨ What's New in 26.10.16 Rose

- 🎮 **Godot Engine support added** — create a Godot project and launch it with the green Play button in the Godot Engine.
- 🐍 **Python support is in development** — more than 100 Python modules have been made to work on Android; full MobileStudio integration is not complete yet.
- 🎨 **UI redesign in progress** — the interface is being refined to improve usability.
- 💬 **Community support** — join the [official Discord server](https://discord.com/invite/eDc5tXfhB2) to report bugs, share feedback, and learn about beta builds.

> [!IMPORTANT]
> The release tag is `MobileStudio_26.10.16-Rose`. The APK asset currently attached to this release is named `MobileStudio-26.10.15-1.Rose.apk`; the direct download button below points to that exact asset.


### 🖥️ Windows `.exe` Build Support

- ✅ Build Windows `.exe` applications using **Clang**
- 🚧 Run `.exe` applications with **Box64 + Wine** — under development
- 🛠️ Work toward a broader development environment directly on Android

### 🐚 StudioShell

StudioShell brings command-line development tools to MobileStudio using binaries ported or built for `arm64-v8a`.

- Git
- cURL
- tar
- Core command-line utilities

StudioShell is designed to use native ARM64 tools rather than a proot-based Linux environment.

### 🤖 AI-Assisted Coding

Starting with **26.10.16 Rose**, MobileStudio supports AI coding through API-connected services and local models powered by **llama.cpp**.

- AI-assisted code generation
- AI-driven code editing
- Code analysis
- Error investigation
- API model connections
- Local model inference with llama.cpp

### 🎮 Game Development

Create games directly on your Android device.

- ✅ Vulkan-based rendering
- ✅ Lua scripting
- ✅ Build and play projects on-device
- ✅ Godot Engine support

> [!NOTE]
> Feature availability and stability can vary by device and project. MobileStudio is actively developed.

## 🔍 Why MobileStudio?

Many Android coding apps focus on editing code, while the actual build process still happens on a PC. MobileStudio aims to bring a real development workflow to Android.

- **On-device Gradle builds** — compile Android projects directly on your device.
- **Native ARM64 tooling** — use command-line tools built for `arm64-v8a`.
- **No root required** — designed to work within Android's app environment.
- **Integrated development workflow** — editor, diagnostics, terminal, build logs, and APK installation.
- **AI-assisted development** — connect API models or run supported local models.
- **Beyond Android apps** — native projects and game development are also part of the toolkit.

## 🚀 Quick Start

1. Download the recommended **Rose 26.10.16 APK** from [this direct link](https://github.com/MobileStudio-AndroidIDE/MobileStudio_AndroidIDE/releases/download/MobileStudio_26.10.16-Rose/MobileStudio-26.10.15-1.Rose.apk), or review the [release notes](https://github.com/MobileStudio-AndroidIDE/MobileStudio_AndroidIDE/releases/tag/MobileStudio_26.10.16-Rose).
2. Install and open the app on your Android device.
3. Import an existing Gradle-based Android project or create one.
4. Open the project and tap **Build**.
5. Review the build output and install the generated APK when available.

**No PC. No root. Build right on your phone.**

## ❓ FAQ · Frequently Asked Questions

<details>
<summary><b>Do I need root access?</b></summary>

No. MobileStudio is designed to run without root access.
</details>

<details>
<summary><b>Can I build native C/C++ projects with the NDK?</b></summary>

Yes. NDK support is available starting with MobileStudio 26.10.16 Rose.
</details>

<details>
<summary><b>Is JDK 21 supported?</b></summary>

Yes. JDK 21 is supported starting with 26.10.16 Rose and is recommended.
</details>

<details>
<summary><b>Which Gradle versions are supported?</b></summary>

Gradle 8.2, 8.7, 8.8+, 9.7.0, and 9.8.0 are supported. Gradle 8.2 is a legacy version and is not recommended.
</details>

<details>
<summary><b>Can I use AI coding features?</b></summary>

Yes. Starting with 26.10.16 Rose, you can connect AI models through APIs or use supported local models powered by llama.cpp. AI features include code generation, code editing, and analysis.
</details>

<details>
<summary><b>Does MobileStudio support game development?</b></summary>

Yes. MobileStudio supports Vulkan-based rendering, Lua scripting, and Godot Engine for on-device game development.
</details>

<details>
<summary><b>Can MobileStudio run Windows applications?</b></summary>

Clang-based `.exe` building is supported. Running Windows applications through Box64 + Wine is still under development.
</details>

<details>
<summary><b>Does StudioShell use proot or an emulator?</b></summary>

StudioShell is designed around native `arm64-v8a` command-line tools and does not require a proot-based Linux environment.
</details>

<details>
<summary><b>Are all features stable?</b></summary>

Not yet. MobileStudio is actively developed, and some features may be experimental or device-dependent.
</details>

## 🔍 MobileStudio가 특별한 이유

대부분의 Android 코딩 앱은 코드 편집에 집중하며, 실제 빌드는 PC에서 진행해야 하는 경우가 많습니다. MobileStudio는 Android 기기에서 개발 과정을 직접 수행하는 것을 목표로 합니다.

- **온디바이스 Gradle 빌드** — Android 프로젝트를 기기에서 직접 컴파일
- **ARM64 네이티브 도구** — `arm64-v8a`용으로 빌드된 명령줄 도구 사용
- **루트 불필요** — Android 앱 환경에서 동작하도록 설계
- **통합 개발 환경** — 편집기, 진단, 터미널, 빌드 로그, APK 설치
- **AI 기반 개발** — API 모델 연결 또는 지원되는 로컬 모델 실행
- **Android를 넘어** — 네이티브 프로젝트와 게임 개발도 지원

3. 기존 Gradle 기반 Android 프로젝트를 가져오거나 새 프로젝트를 만듭니다.
4. 프로젝트를 열고 **Build** 버튼을 누릅니다.
5. 빌드 로그를 확인하고 생성된 APK를 설치합니다.

## ❓ 자주 묻는 질문

<details>
<summary><b>루트 권한이 필요한가요?</b></summary>

아니요. MobileStudio는 루트 권한 없이 동작하도록 설계되었습니다.
</details>

<details>
<summary><b>NDK로 C/C++ 프로젝트를 빌드할 수 있나요?</b></summary>

네. MobileStudio 26.10.16 Rose부터 NDK 지원을 사용할 수 있습니다.
</details>

<details>
<summary><b>JDK 21을 지원하나요?</b></summary>

네. 26.10.16 Rose부터 JDK 21을 지원하며 권장합니다.
</details>

<details>
<summary><b>어떤 Gradle 버전을 지원하나요?</b></summary>

Gradle 8.2, 8.7, 8.8 이상, 9.7.0, 9.8.0을 지원합니다. Gradle 8.2는 구버전이므로 권장하지 않습니다.
</details>

<details>
<summary><b>AI 코딩 기능을 사용할 수 있나요?</b></summary>

네. 26.10.16 Rose부터 API를 통한 모델 연결과 llama.cpp 기반 로컬 모델을 지원합니다. 코드 생성, 수정, 분석 등의 기능을 제공합니다.
</details>

<details>
<summary><b>게임 개발을 지원하나요?</b></summary>

네. Vulkan 렌더링, Lua 스크립팅, Godot 엔진을 이용한 기기 내 게임 개발을 지원합니다.
</details>

<details>
<summary><b>Windows 프로그램을 실행할 수 있나요?</b></summary>

Clang을 이용한 `.exe` 빌드는 지원합니다. Box64 + Wine을 통한 Windows 애플리케이션 실행은 아직 개발 중입니다.
</details>

<details>
<summary><b>StudioShell은 proot나 에뮬레이터를 사용하나요?</b></summary>

StudioShell은 `arm64-v8a` 네이티브 명령줄 도구를 기반으로 설계되었으며, proot 기반 Linux 환경을 필요로 하지 않습니다.
</details>

<details>
<summary><b>모든 기능이 안정적인가요?</b></summary>

아직은 아닙니다. MobileStudio는 활발히 개발 중이며 일부 기능은 실험적이거나 기기에 따라 다르게 동작할 수 있습니다.
</details>
